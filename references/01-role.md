# 角色：名称稳定、详细设计、观众吸引力

## 建档与版本

制作来源中实际可见、实际发声或参与动作且需要复用的单体、群像、动物角色可以建档。只被提及的人物不建档。画外台词仍可能属于已有角色，不因未入画遗漏声线需求；无人格旁白不强行生成人物。

同一人物的别名须有指代证据。不能因“姑娘”“老爷”等通用称谓相同跨场合并。版本包括幼年、成年、真身、伪装、嫁衣、朝服等真正需要独立制作的形态；是否独立取决于生成、辨认和连续复用需求，单次重要造型也可独立。各版本主名不改，内部共享 `entity_id`，使用不同 `id`、`variant`，别名按各自来源填写。

永久疤痕、胎记、长期残疾属于稳定设计；贯穿多镜头的伤势或破衣可建连续性版本。流汗、瞬间表情、当镜走位等属于镜头状态，内部留存，不写进基础人设。普通佩饰写入人设，不因交接、丢失或被触碰就独立建道具；只有明确承担信物、身世凭证、特殊能力等关键剧情作用时另建道具并记录对应关系。

## 五行输出

```text
【姓名】: 原文主名
【别名】: 原文别名，以顿号分隔；没有写无
【颜值定位】: 造型版本：基础；具体的轮廓、五官和气质美学定位
【人设描述】: 面部特征：……；发型：……；发饰：……；身材比例：……；衣着：……；气质：……
【声线类型】: 符合角色的固定声线，或无对白（仅形象）/非语言鸣叫/电子音/中性音
```

群像首行改为 `【群像】`。姓名、别名、造型版本与内部记录一致。五行之外不追加镜头、出处、身份关系或剧情说明；来源与归属放内部记录。声线根据实际需要填写，不强制全部选择男音或女音。

### 六项要具体

| 项目 | 描述重点 |
|---|---|
| 面部特征 | 脸型和骨相、眉形、眼型与瞳色、鼻唇关系、肤色肤质；稳定疤痕与痣按原文保留。用视觉年龄感体现时期，不写人物履历。 |
| 发型 | 发色、长度、分缝、发际、刘海、发髻/辫的结构及位置、鬓发与发丝整洁度。 |
| 发饰 | 原文有则保留；没有可明确写“无发饰，发束自然收拢”。存在时写形状、位置、数量、材质、工艺和表面质感，不能为填字段硬添珠玉。 |
| 身材比例 | 身高或相对高度、头身关系、肩腰髋比例、体态与重心，符合项目整体比例。儿童保留幼态，老人保留骨架与年龄感。 |
| 衣着 | 从内层到外层、领袖和下装、腰带、鞋袜；写主次色、面料织纹、厚薄、接缝、磨损或养护程度。单一棉布也可有充分工艺与层次，不要求材质种类配额。 |
| 气质 | 稳定的目光、面部张力、仪态和视觉感受，区别于瞬时情绪与剧情动作。 |

默认单体【人设描述】约 650–1000 中文字符，群像按人数适量增加。这是质量参考，不作为机械上下限；短于参考时检查是否遗漏关键结构，长于参考时删重复和无关设定。每项写成明确可见的形态与质感，不以抽象评价、剧情履历或画风标签补字数。

【人设描述】必须是一条自身完整的视觉提示词，复制该行的六项内容即可使用。不要加入“生图时请”“参见小说”“按角色设定补充”等二次加工指令；不默认添加三视图、白底、站姿、镜头焦距或构图模板，除非用户明确要求。声线、别名和造型版本留在其对应行，不进入六项视觉描述。

## 美术提升顺序

1. 锁定硬约束：小说/剧本已明确的五官、体态、疤痕、年龄感、服装和阶层线索，制作分镜实际要求的版本。
2. 选择人物的吸引力方向：清秀、端正、英气、温润、灵动、冷峻、威严、慈和或有表现力的独特外貌；不把“好看”限定为单一偶像脸。
3. 统一骨相与五官比例，安排发型对脸型的修饰、服装轮廓与体态的呼应；色彩有主次，材质呈现可靠。
4. 至少建立一处适合该人物的辨识特征，例如眉眼走势、发髻轮廓、领口结构、低调配饰或稳定色彩关系。不要凭空新增纹身、权力徽记等剧情线索。
5. 近景能读五官和工艺，远景能读轮廓和配色。对照同场人物，避免同脸、同发、同装。

贫穷可以是洗旧但有层次的棉麻、清晰缝线和克制配色；不能自动变成五官失衡、满脸污秽、服装毫无设计。反派可以有精致或强烈的造型；不自动丑化。原文明写丑陋、粗壮、肥胖、病弱或年老时保留相应特征，通过结构、质感和表现力提升美术性，不篡改为年轻纤瘦。美术完成度是可复核目标，不能承诺所有观众一定喜欢。

## 群像与非人类

- 先核对独立成员，再建立剩余匿名群体。内部记录总人数、独立成员、当前匿名人数，防止重复调度；历史总规模与当前有效人数分开。
- 有确数照原文；模糊人数只作不改变剧情规模的最小设计补全。少人数逐人区分，多人数按子组区分且人数之和相等。
- 有表演需求、需稳定复用的动物独立归角色，不能嵌入场景；普通坐骑也不默认列为道具。确有特殊剧情物件属性且符合道具门槛时才例外归道具，一次只归一种类型。
- 只有声音的系统使用电子音等声音说明。确有可见系统角色时才设计其外貌；纯声音形态的六项可明确写“不具可见形体，无对应面部/毛发/衣着”等，不能补造萌宠。
- 人体六项对动物可使用口鼻/眼部、毛发鳞羽、佩饰、体长体态、鞍具/覆盖物、气质；不适用项写明确的不存在状态。
