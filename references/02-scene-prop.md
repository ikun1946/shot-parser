# 场景与道具美术规范

## 场景

**全部场景都是用于生图的纯环境空镜，不得包含任何角色。** 禁止人物、群像、路人、活体动物、远景小人、背影、剪影、镜中倒影、窗外人影和可辨认角色画像。原镜头有角色也只提取环境，角色和动作另归角色资产与分镜。空间可保留通道、家具使用痕迹等信息，但不写“某人站在桌旁”或“远处有模糊人群”。美术控制必须明确包含“纯环境空镜，无人物、无动物”；不能一边写该声明，一边在前文放入角色。地名含人名、建筑“人字梁”或抽象装饰纹样不等于有角色。

字段顺序如下，均写明确标签，以中文分号分隔；字段内部可用逗号和句号。名称、别名和版本与内部记录一致。

```text
场景名称：原文主名；别名：原文别名或无；版本：基础；时间：白天（清晨、午后）；场景类型：室内；时代与地域：……；空间结构：……；视觉陈设与标志物：……；材质与工艺：……；色彩体系：……；光影：……；氛围与情绪：……；视觉记忆点：……；美术控制：纯环境空镜，无人物、无动物，……
```

- **空间结构**：封闭程度、形状、进深、层高、门窗与通道的位置、前中后景层次和行动余量。已有分镜确认的布局先固定，不为美化阻断走位。
- **陈设**：选与生活、时代和剧情有关的可见物，写形制、材质、位置、大小关系与新旧。空牢房、雪原、祭坛可以保持少量元素，不设六件物品配额。
- **材质工艺**：写主要表面的纹理、接缝、反光和使用痕迹；同一材质的差异可丰富空间，不要求四种材质。贫寒、破败也要有可信结构、层次和细节。
- **色彩**：有主色、辅色与必要点缀，写明冷暖、明度和饱和度关系；构成清楚空间层次，不堆色名。
- **光影**：光源、方向、软硬、亮暗层次和空间关系与时段一致，不用渲染器参数。清晨与午后可归白天，但明显不同的光线分别建立可制作版本。
- **记忆点与控制**：用具体结构或陈设建立辨识度，减少无关装饰、塑料质感和不合时代的装修。真实材质、清楚轮廓和可读空间优先。

默认约 650–1100 中文字符；依据场景复杂程度调整。除名称、别名、版本等调度信息外，视觉字段连起来即是完整文生图提示词：主体空间、结构、位置、材质、色彩、光线和记忆点均具体自洽，不依赖其他资产补读。描述稳定空间应综合该地点全部相关镜头，而非只保留某个特写中的局部。没出现的非关键细节可按世界观设计，但不能增加剧情相关密道、宗教徽记、权力标识或改变关键门窗结构。不自动加人物、画风、航拍或镜头模板。

### 室内外与可见范围

按当前实际空间判定：封闭房间、封闭车厢和船舱是室内；露天街道和甲板是室外；有遮顶且开放的门廊、敞篷结构等按实际情况为半室外。公开谈话不自动等于室外，私密谈话也不自动等于室内。

室内主体必须是室内结构，不能写成整座宅院鸟瞰。原分镜明确通过门窗可见院子、天空或远山时，描述其边框、遮挡和局部可见关系，并在内部来源中保留依据；不能仅因出现“天空”等字就拒绝。无来源时不主动补大幅外景。

### 名称、时间与版本

地点名从场景栏拆出，去掉独立的时段与内外标注，保留地点本身全部文字。地名本来含“夜”“晨”或连字符时不可截断。原栏叫“刘家正厅”，主名不能改成“刘府会客厅”；确认同一地点的“正厅”登记为别名。

时间使用白天、傍晚、夜晚，实际时段放括号；清晨/上午/中午/午后/下午归白天，黄昏/日落/入夜归傍晚，深夜/子夜/凌晨归夜晚。黎明、微明按具体光照归组并复核。无时段线索时内部列待定，不伪称原文事实；设计补全应注明其性质，不能改剧情时序。

同地点可按时间、天气和持续环境状态拆版本，版本字段区分，主名不加后缀。同档且光照一致可合并，明显不同光照不强并。时代、材质、形制可用内部统一基准，各资产仍完整写出本条适用属性，不跨场景指代。

## 道具

**只提取特殊剧情道具，不做所有物件的清单。** 是否被拿起、使用、交接、破坏、反复出现或需要连续调度，均不能单独构成建档理由。

| 情形 | 是否独立建档 |
|---|---|
| 定情信物、认亲玉佩、身份令牌、家传凭证 | 原文明确承担相应作用时建立 |
| 关键密信、遗诏、罪证、凶器、决定反转的物证 | 原文明确其信息与因果作用时建立 |
| 特殊法器、唯一武器、开启关键地点的特定钥匙 | 原文明确特殊能力、唯一性或关键用途时建立 |
| 普通茶盏、碗筷、桌椅、扫帚、一般工具、普通布包 | 不独立建立；按需写入陈设、服饰或镜头状态 |
| 外形普通但实际装有毒物的茶盏、藏有密信的布包 | 因原文明确的关键作用建立，不能只因它是茶盏或布包排除 |
| 只有昂贵、精美、具名或被特写，没有特殊剧情作用 | 不独立建立；名称和外观本身不足以证明重要性 |

每条独立道具内部必填 `importance`：具体类别、真实剧情作用、依据来源行。没有原文依据就不建立，不为通过校验编造信物、铭文、归属或能力。视觉描述只写外观，不把人物关系与剧情梗概塞进文生图提示词；依据留在内部数据。

普通杯碗等可作为场景陈设被详细描述，但没有独立的道具条目。用户明确指定某物独立建档时可按要求处理，内部注明“用户指定”，不伪称原文把它写成信物。

```text
道具名称：原文主名；别名：原文别名或无；版本：基础；道具类别：……；美学定位：……；外形：……；纹样与工艺：……；特征：……；材质：……；色彩与光泽：……；使用状态：……；美术控制：……
```

默认约 350–650 中文字符。视觉字段自身组成可直接使用的文生图提示词，重点写尺寸或相对大小、结构和比例、边缘厚薄、握持/开启/连接部位、纹样的具体位置、制作工艺、表面质感、反光、磨损与功能识别。信物不必金玉化，粗木令牌、素布香囊也可有可靠材料和细致结构，材质服从原文。纹样不存在可写“素面，无纹样，口沿细磨”，不能为凑字段新增谜题。不自动加展示台、白底、漂浮陈列或角色手持姿态。

同形物件的所有权、来历和交接链不同，应保留不同实体。原文“断剑”就是调用名时可以用“断剑”；同一把铁剑折断后可为铁剑的断裂版本，“断剑”作为实际别名并保留适用来源。内部分清实体和版本，不用相似百分比替代判断。

使用状态写版本的稳定状态；当前握在谁手中、飞行轨迹、落地瞬间等写镜头状态。原文明写残破、粗糙或廉价要保留，通过比例、纹理和制造逻辑提高美术完成度。
