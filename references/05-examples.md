# 行为样例与验收

## 合成示例：制作分镜与小说互补

分镜：

```text
## 第1集
段落1｜总时长12秒
**场景：** 刘家正厅 清晨 室内
出场人物：阿月、掌柜
道具：双鱼玉佩、白瓷茶盏
画面：姑娘端起白瓷茶盏。阿月抬眼看向掌柜。
台词：阿月：双鱼玉佩是母亲留下的认亲信物。
```

辅助小说设定：故事发生在古代乡村环境。阿月衣着贫寒，左眉有一道幼时留下的细疤，气质清秀；掌柜脸颊圆润，性格精明。双鱼玉佩为青白玉，顶部系素灰棉绳，没有文字铭记。

正确决策：

- 角色主名用“阿月”“掌柜”，由上下文确认“姑娘”属于阿月后加别名；不改名“清秀少女”“刘掌柜”。
- 保留阿月左眉细疤和贫寒服装，用协调五官、发型轮廓、灰蓝棉麻层次与细致缝线提升美感。不能擦掉疤痕或变成华服富家女。
- 保留掌柜圆润的脸型，以眉眼、胡须或服装轮廓形成辨识，不自动年轻化，也不因精明就丑化。
- 场景主名为“刘家正厅”，时间写“白天（清晨）”；“清晨”不拼入名称。
- 独立道具只建立“双鱼玉佩”，因为原文明说它是认亲信物；“白瓷茶盏”只是普通饮具，虽被端起也不独立建档，归入正厅陈设或镜头状态。
- 正厅输出纯环境空镜，不能出现阿月、掌柜或任何其他角色，窗外也不出现人物或动物。
- 有来源的窗外院景可以作为门窗框住的局部内容；没有来源就不主动写院落全景。

## 完整视觉描述示例

以下三条展示默认精细程度；这是上述项目的设计补全示范，不是所有项目的统一服装和空间模板。三条分别展示一个资产，不代表上方两人分镜的全量资产清单。角色复制【人设描述】的六项内容即可用作文生图提示词；场景、道具直接使用各视觉字段。不附加任何画风标签。

## 必测行为

运行 `python -B -m unittest discover -s tests -v`。覆盖完整 v2 名称映射、别名、同名版本、来源行、辅助来源越界、重复 ID/键、合法旧疤、单材质服装、无发饰、声音形态、道具字段缺失、画风词、场景时间、场景无角色、特殊道具依据、普通用品排除、导出陈旧文件、UTF-8 与分隔符。

自动测试以真实输入输出和失败行为为准，不测试一句话是否被逐字复制。规则改动后用一个新的小型分镜和辅助小说做完整人工前向验证，复核来源忠实、美术具体性与名称覆盖，不仅运行格式脚本。
