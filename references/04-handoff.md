# 交付与下游

资产是本技能的完整交付，默认包含根部 `资产.json` 和分类 TXT。最终回复单独提供 JSON 文件链接或路径，并说明分类 TXT 位置、三类数量、实际核对了哪些制作来源，以及真实存在的待定问题；不强制追加询问。只有用户明确仅要 TXT 或不保存 JSON 时，才省略 JSON。

交接时保持场景为空环境，不把分镜中的人物重新加入场景提示词。道具数量只统计筛选后的特殊剧情物件；普通陈设不为凑数量单独转成道具提示词。没有特殊道具就不生成道具文件夹。

- 用户只要求资产：交付完成后结束。
- 用户已明确要求后续提示词：按既有授权继续，先发现可用的下游能力，传入完整 JSON、三类 TXT 及用户已选风格；用 JSON 中的名称、别名、实体和版本映射保持调用一致。
- 用户尚未要求生成图片或视频：不要自动发起生成、付费调用或发布。
- 下游能力不可用：交付已完成资产，说明接续部分不可用，不把旧技能名写成硬依赖。
- 跨会话默认传 JSON + TXT 包；来源映射、排除理由和道具重要性依据随 JSON 一并保留，不等用户追问后再从 TXT 重建。后续修改应依据同一制作来源和 JSON 中的实体、版本记录重新核对。

用户要求改资产时保留原包，生成新目录；增量范围明确时仅重做新增或变化实体，再全局核对调用名及版本，不重写已经认可的无关角色。
